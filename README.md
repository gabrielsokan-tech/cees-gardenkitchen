# Cees Garden Kitchen

A responsive website for a Nigerian restaurant in Abuja, built for the New Horizon HTML, CSS and JavaScript course project.

**Author:** Adesokan Opeoluwa Gabriel (GitHub: gabrielsokan-tech)

## Pages
- `index.html` – Home (welcome, intro, favourites)
- `about.html` – About (story, mission, vision, objectives)
- `menu.html` – Menu and services (6 items, filterable)
- `contact.html` – Contact details and validated contact form

## Technologies
- **HTML5** – semantic elements (`header`, `nav`, `main`, `section`, `article`, `footer`, `address`), lists, forms, images
- **CSS3** – external stylesheet, selectors and combinators, box model, sticky/fixed positioning
- **Flexbox** – navigation bar, features strip, footer
- **Grid** – menu cards, about layout, contact layout
- **Media queries** – tablet (900px) and mobile (700px) breakpoints
- **JavaScript** – mobile menu toggle, menu filter, back-to-top button, contact form validation with feedback

## Notes
- The contact form only validates input; no message is sent because no backend is connected.
- Images are linked from Wikimedia Commons.
- Menu prices are sample prices.

## Run locally
Open `index.html` in a browser.
